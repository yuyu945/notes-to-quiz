# 课程笔记学习助手设计

## 目标与范围

在本地启动一个 Streamlit 单页应用，使用 LangChain 调用 DeepSeek 在线 API。
用户上传一份 UTF-8 编码的 `.txt` 或 `.md` 笔记，先提炼知识点，再生成三道
单选练习题；提交答案后在本地计算成绩并展示解析。
不做账号、数据库、PDF、向量检索或多轮对话。

## 主流程

1. 用户上传笔记。应用校验扩展名、UTF-8 编码、非空内容与长度上限，并展示文件名和内容预览。
2. 用户点击“提炼知识点”。LangChain 将笔记和固定提示词交给 DeepSeek，页面展示简明的知识点列表。
3. 用户点击“生成练习题”。模型按固定结构返回三道单选题，每题四个选项、一个正确选项和解析。应用校验结构后隐藏答案并显示题目。
4. 用户逐题选择答案并提交。应用在本地评分，逐题显示正确答案与解析，不为评分再次调用 API。
5. 更换文件时清除旧知识点、题目及作答状态，避免内容混用。

每次生成只处理当前这一份笔记。输入上限采用明确的字符数限制；
超过限制时要求用户缩短笔记，不做静默截断。模型输出无法解析时给出可重试的提示。

## 组件与数据边界

- `app.py`：Streamlit 页面与 session state，负责文件切换、操作按钮和结果呈现。
- `notes.py`：文件名、编码、空内容及长度验证；返回纯文本，不写磁盘。
- `study.py`：LangChain 模型调用、提示词、题目结构验证及本地评分。
- `tests/`：使用假模型或替身覆盖文件验证、题目格式、评分及主要页面状态，不依赖真实密钥。

只有点击生成按钮时才发送笔记内容至 DeepSeek。页面不记录 API Key，
也不把笔记、模型原始响应写入日志或仓库。API Key 从 `DEEPSEEK_API_KEY`
环境变量读取；本机可用 `.env` 加载，仓库只提供 `.env.example`，
`.gitignore` 忽略 `.env`。模型名也用环境变量配置，避免固定依赖某一型号。

## 交付与验证

`README.md` 说明功能、前置条件、安装、配置、启动、演示步骤、隐私说明及
开源仓库链接。链接只能在真实远端仓库创建后填写；本地完成不等于已公开。
提供一份不含敏感信息的示例笔记供演示。

验证分两层：自动化测试和静态检查覆盖无密钥路径；有可用 Key 时再走一次
上传、提炼、出题、作答的真实 API 流程。若无 Key，则明确报告线上流程未实测，
不把页面能启动当作完整验证。

主要风险是 API 计费或限流、网络故障、模型输出格式偏差，以及笔记会被发送到
第三方服务。界面应给出简短可行动的错误信息；README 明确提醒不要上传敏感笔记。
